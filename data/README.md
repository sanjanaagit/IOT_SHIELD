# Data Directory (`data/`)

This directory is designated for IoT network traffic datasets and telemetry.

## Directory Structure
- `raw/`: Raw network capture files and dataset dumps (e.g., CIC-IoT-2023, TON_IoT, BoT-IoT, etc.). Excluded from git.
- `processed/`: Cleaned, transformed, and feature-engineered datasets ready for model training. Excluded from git.
