# Machine Learning Module (`ml/`)

This directory will house the machine learning pipelines, feature engineering, model training, evaluation scripts, and explainability modules for IoT intrusion detection.

## Planned Structure (Future Stages)
- `pipelines/`: Data ingestion, preprocessing, and feature scaling pipelines
- `training/`: Supervised and unsupervised model training routines (Random Forest, XGBoost, Autoencoders)
- `evaluation/`: Classification metrics, confusion matrices, ROC-AUC curves
- `explainability/`: SHAP-based local and global model explanations
